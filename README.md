# Pigeon

A Mac app for DJs. Give it a Spotify playlist and it finds each track on Soulseek as a lossless file, preferring the
extended or original mix over the radio edit. It checks every download with a spectral analysis before filing it as
FLAC in your music library, and lets you sort the library into branches: flat playlists for rekordbox.

## Download

**[Download the latest version](https://github.com/lSANCHOl/pigeon/releases/latest)**, open the DMG and drag Pigeon to
Applications. After that, Pigeon checks for new versions once a day and offers to install them.

## Requirements

- A Mac with Apple silicon, on macOS 15 or later
- A Soulseek account: Pigeon registers a new name the first time it logs in
